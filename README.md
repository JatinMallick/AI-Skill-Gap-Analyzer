# AI Skill Gap Analyzer

## Description
AI Skill Gap Analyzer is an AI-powered system that analyzes resumes, predicts suitable job roles, and identifies missing skills using Natural Language Processing and Machine Learning.

The system helps users understand which skills they need to improve to match industry job requirements.

---

## Features
- Resume parsing from PDF
- Skill extraction using NLP
- Job role prediction using Machine Learning
- Top career recommendations
- Skill gap detection
- Match score calculation
- Skill gap visualization
- Flask web application interface

---

## Tech Stack
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Flask
- TF-IDF Vectorization
- Logistic Regression

---

## Project Architecture

Resume PDF  
↓

↓
